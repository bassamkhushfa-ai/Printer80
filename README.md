# محرر وطباعة الفواتير الحرارية 80mm (Thermal Receipt Editor)

تطبيق ويب خفيف ومتكامل مخصص لتحرير وطباعة الفواتير والإيصالات الخاصة بطابعات الورق الحراري بعرض **80 مم** (80mm Thermal Printer).

## 🚀 المميزات
- **طباعة 80 مم دقيقة:** محاكاة ومعاينة مباشرة لورق الطباعة الحراري بمقاس 80mm وتهيئة الاستدعاء التلقائي لخاصية `@media print`.
- **أدوات تحرير شبيهة بالـ Word:** تحرير النصوص والقيم والجداول مباشرة بالنقر عليها داخل الفاتورة.
- **مولد أكواد QR و Barcode:** إمكانية إنشاء كود الاستجابة السريعة (QR) أو باركود المنتجات وتضمينه فورياً في الفاتورة.
- **حساب تلقائي:** حساب مجاميع المبيعات والضرائب تلقائياً.
- **بدون تثبيت تعقيدات:** يشتغل مباشرة عبر أي متصفح ويب (Chrome, Edge, Firefox).

## 🛠️ طريقة التثبيت والرفع على GitHub

1. قم بإنشاء مستودع جديد (Repository) على حسابه في GitHub باسم `thermal-receipt-printer`.
2. قم بفك الضغط عن هذا الملف.
3. قم برفع ملفات المشروع (`index.html` و `README.md`) إلى مستودع GitHub.
4. (اختياري) يمكنك تفعيل خدمة **GitHub Pages** لتشغيل التطبيق أونلاين مباشرة عبر المتصفح:
   - اذهب إلى إعدادات المستودع **Settings** -> **Pages**.
   - اختر الفرع `main` ثم احفظ التغييرات.

## 🖨️ كيفية ضبط الطباعة
عند ضغط زر **طباعة الفاتورة**:
1. اختر طابعة الـ 80mm الخاصة بك.
2. اختر مقاس الورق **Roll Paper 80mm** أو **80mm x Receipt**.
3. قم بإلغاء خيار **Headers and footers** (الترويسة والتذييل) من إعدادات المتصفح لإزالة تاريخ ورابط المتصفح من الورقة.
